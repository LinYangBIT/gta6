# Sunset Coast — 霓虹海滨都市

[公开体验](https://sunset-coast-drive-linyang.yanglinchasel.chatgpt.site) · [Blender 与 GitHub 工程](https://github.com/LinYangBIT/gta6)

横屏优先的原创开放城市原型。从人物步行开始，可领取委托、驾驶场景中的任意车辆、下车交付包裹，或自由探索持续生成的街区。城市、角色和车辆在浏览器中本地运行；游戏资源本地托管，GTA V 原声通过 Spotify 官方播放器加载。

## 操作

- 步行：WASD / 方向键移动，Shift 奔跑，E 与联络人交谈或上下车。
- 驾驶：W 加速，S 减速与倒车，A / D 转向，空格手刹；停稳后 E 下车。
- 镜头：拖动画面自由环视，C 切换跟随、侧面、第一人称和俯瞰，V 回正；滚轮 / 双指缩放。
- 音乐：点击“进入城市”即启动默认 BGM，等待 GTA V 原声时由内置 COAST FM 衔接，原声实际开始后停止内置音乐；M 打开 / 收起设置，顶部播放 / 暂停键控制音乐，N 切歌。收起设置或返回菜单不会停止音乐。封面上方同样保留这两个音乐按钮。引擎声默认开启，点击进城时解锁、上车后发声；随速度平滑变化，步行、CG、菜单和后台静音。右上角声音按钮可单独关闭，重新进入会保留本次手动关闭状态。Esc 打开菜单，R 回到起点并重新开始委托。
- 转向配置：点右上角“操控设置”按钮，转向幅度可调 60%–200%，响应速度 60%–180%；默认 130% / 115%。滑块即时生效并保存到本机，换车和换城市保留，可一键恢复推荐。
- 清晰度：操作指南中可选自动、高清、均衡和流畅。自动模式优先高清；显式选择高清会保留该设置。
- 手机横屏：左侧摇杆移动或转向，右侧奔跑 / 油门等动作键，中间右侧交互按钮上下车和领取任务。右侧空白画面可拖动环视。竖屏提供旋转提示，也可选择继续。

开始任务后的流程是步行到联络人领取摄影器材，任选一辆车前往黄色停车标记，停稳后下车交付，获得 $300。之后可继续接取按城市种子生成的委托；换车不丢失包裹。自由探索模式暂时隐藏任务指引。进度和车辆位置为当前会话状态；菜单可继续，重新加载或重置会重新开始。

首次进入有约 8 秒的实时 CG：掠过海滨、经过酒店街景，再落到步行角色身后。可点击“跳过 CG”或按 Esc 跳过；动画期间冻结移动，返回菜单后继续仅作短过渡，开启“减少动态效果”时不播放飞行镜头。

默认转向比上一版更灵活，半秒持续打轮的偏航在测试车速下增加约 30%–37%。可独立调节转向幅度与响应速度，仍保留渐进响应、高速稳定限制和快速回正：轻推摇杆适合修正方向，持续推转向仍可完成低速街口转弯，高速急打轮不再瞬间大幅甩向。巡航中任意手动操控会接管。横屏摇杆扩大至 128px，油门至 72×150px，镜头按钮 44px；音乐默认收起为顶部 98×52px 的按钮条，内含两个 44px 按钮，释放任务和操控区域。

## 城市与视觉

最新视觉改为可读性优先的赛博朋克暮景：蓝紫天空、青色与品红灯带、琥珀灯窗，建筑主体采用石墨、青蓝与紫灰，近景和远景共享配色。湿润路面使用较低粗糙度和不规则区域，保留车道与路缘的清晰对比。

建筑增加立体媒体屏、边缘灯轨、屋顶天线、设备棚及管线；街边店招使用本地生成的原创科技主题字样。车辆使用深色金属漆，增加青蓝侧裙灯、分段前灯、洋红尾灯与引擎盖细节。车辆继续使用 17 组共享实例批次，近景跑车仅补充两组灯条；城市继续复用已有发光材质，不为每栋建筑添加灯光。

起点改为按网络截图重建可见建筑外观的海洋大道街区：弯曲的滨海主路、带中央绿岛的环岛、斜向连接路、酒店后巷、停车带和跨湾连接路。路网、车辆停放、碰撞、自动驾驶与小地图共用真实道路数据；离开海滨街区后继续进入无限生成的五类城区。

Colony、Dominion、Dixon 和 Coral 酒店采用分别制作的外观，加入圆角墙体、立体窗框与窗台、玻璃分格、阳台栏杆、入口、咖啡座、竖向招牌及屋顶设备。海边有棕榈公园、步道、沙滩遮阳伞和救生亭。车辆包含跑车、轿车、SUV；所有显示的汽车均可驾驶。角色有步行 / 奔跑动作，任务联系人和街边行人。

## 音乐

默认启用入场 BGM，并优先衔接 **GTA V · THE SCORE 官方原声**。城市加载时预先准备 Spotify；点击“进入城市”的同一次操作中启动内置 COAST FM 并请求原声播放。只在收到 Spotify 实际播放事件后关闭内置音乐，避免等待原声或平台拒播时始终无声；播放中的内置曲目明确标注为 COAST FM，不当作 GTA 原声。收起面板、返回封面、打开帮助和旋转设备都不会主动停止音乐。播放 / 暂停键同时管理入场 BGM 与原声；用户手动暂停后不会因重新进入而强行恢复。观看 Blender 短片时暂时暂停，关闭后恢复此前状态。

也可选择两首原创合成器曲目的 COAST FM，或选择本机音频；本机音频选择后尝试自动播放并循环；文件只在本机使用，不上传，收起设置仍继续播放。浏览器拒绝自动播放时会显示播放提示；操作系统可能限制后台标签页或锁屏时的音频，本站不保证锁屏播放。

GTA V 原声通过 [官方 Spotify 专辑](https://open.spotify.com/album/5EJAJsaHhQYLwVbynpcGkD) 播放。默认使用 [Spotify 官方 iFrame API](https://developer.spotify.com/documentation/embeds/references/iframe-api) 尝试启动，实际状态来自播放器事件；不把“播放器已加载”当成正在播放。默认只显示顶部音乐设置与播放 / 暂停两个按钮；点击音符或 M 才展开完整播放器。收起设置仅隐藏面板，保留同一个 iframe 和控制器，不调用暂停或销毁。自动播放、可播放范围受浏览器、Spotify 账号和地区限制；失败时点击顶部音符展开播放器，再点击播放。若 Spotify 控制 API 无法连接，内置 BGM 继续；只有主动选择“打开 GTA V 原声播放器”才让出声音并打开独立原声控件，避免两路音乐重叠。网页不保存、下载或分发商业音轨。

## 高清封面与细节

封面使用 [Rockstar 官方壁纸页](https://www.rockstargames.com/VI/media/artwork-wallpapers) 发布的完整原图：横版 **3840×2160**、竖版 **1080×1920**，保持画面比例和原色。站点保留“非官方可玩场景”标识，官方封面与 Logo 的来源、哈希及版权记录在 `dist/assets/gta6-cover-attribution.json`；它们不属于项目 MIT 资产。

实时场景新增近景窗框、窗台、阳台立杆、门厅灯具、遮棚细节、轮拱、车门缝、灯组、刹车盘与细化轮辐。原有热带配色现已更新为蓝紫暮景与青蓝、洋红霓虹。车辆仍使用 17 组共享绘制批次，远景继续简化，避免把近景细节复制到所有远处建筑。

高清模式启用抗锯齿和更高阴影精度，按屏幕比例提升渲染分辨率；桌面像素预算最高约 4K，手机最高约 420 万像素。自动模式在持续低帧率时逐级平衡清晰度；选择固定高清后不自动降低。新版赛博朋克 Blender 街景与俯瞰预览为 **1920×1080**，使用实际网页几何与近景跑车灯条；离线光照和网页实时渲染会有差异。

本轮把海滨陆侧建筑从 19 栋增加到 133 栋，保留五座地标；外围每个 128 米街区从 4–6 栋增加到 16–22 栋。楼房组成沿街商铺、围合庭院、住宅区和办公楼群，内部留出服务通道。

城市按位置持续生成，近景手机最多 25 块、桌面 49 块；远景窗口分别覆盖 17×17、23×23 块区域（扣除已加载近景）。远处建筑与近处使用同一布局、位置和主体尺寸，靠近时补充细节，并非不可到达的背景图。手机雾化距离延伸至约 930 米，桌面约 1400 米。远景只使用四组实例绘制，不参与远距离阴影；离开的街区会回收，碰撞缓存仍为 48 块。浮动原点保持远距离精度。汽车保留附近3×3街区，最多记忆64辆改动过的车辆，超出历史上限的久远车辆可重新生成。没有固定地图边界，也不会一次创建无限物体。

## 本地运行与检查

```bash
python -m http.server 8080 --directory dist
# 打开 http://localhost:8080
node --test tests/*.test.mjs
```

检查覆盖实际 GLB 加载、走路与驾驶碰撞、所有车型上车、停车安全下车、车辆回收和位置保留、任务顺序与奖励、完整首单流程、海滨道路连通与跨块接缝、密集建筑间距和服务通道、远近景交接及远景内存上限、镜头手势、多点触控、CG 镜头路径、入场与跳过生命周期、渐进转向和高速稳定性、转向配置与本机持久化、入场 BGM 与原声接替、背景播放、默认引擎声与静音生命周期、用户手动暂停、音频切换竞态、原声播放器生命周期、高清像素预算、电台调度和 JS 语法。当前执行环境没有浏览器自动化工具；没有进行手机实机或浏览器画面验收。Blender 离线预览用于检查几何和构图，光照与网页实时渲染会有差异。

## 源码与许可

- `dist/gameplay.js`：人物步行、车辆生成、上下车与碰撞。
- `dist/missions.js`：委托流程、现金奖励和后续任务。
- `dist/actors.js` / `human-model.js`：角色动画与多车型渲染。
- `dist/coast-layout.js`：共享海岸路网、地形、碰撞和路线导航。
- `dist/coast-architecture.js` / `coast-render.js`：细化酒店和海滨街景。
- `dist/urban-architecture.js`：密集商铺、住宅和办公楼的分级细节。
- `dist/city-horizon.js`：与近景同源的有界远景窗口。
- `dist/world-layout.js` / `infinite-city.js`：确定性布局与流式城市。
- `dist/engine-sound.js`：默认开启的独立引擎声、速度音调和驾驶状态静音。
- `dist/soundtrack.js`：独立于设置面板的音乐生命周期、Spotify 官方 API、本地音频与电台。
- `dist/entry-cinematic.js` / `cinematic.css`：实时入场镜头、跳过和减少动态效果。
- `dist/steering-settings.js` / `settings.css`：转向滑块、推荐值与本机偏好保存。
- `dist/render-quality.js`：分辨率、像素预算与自动画质。
- `dist/cover.css` / `music.css`：官方封面展示与可收起的原声设置与紧凑音乐按钮。
- `dist/street-signs.js`：本地生成原创店招图集。
- Blender 原创跑车来自主仓库 `scenes/sunset_coast.blend`；最新可编辑赛博朋克城区快照为 `scenes/cyberpunk_city.blend`，鲜艳暮色旧版为 `scenes/vivid_city.blend`，密集城区旧版快照为 `scenes/dense_city.blend`，海洋大道旧版快照为 `scenes/coastal_district.blend`，人物街景快照为 `scenes/street_life.blend`，旧固定海岸场景仍保留。
- Three.js 0.173.0 使用 MIT，许可在 `dist/vendor/LICENSE.three.txt`。原创代码和资产沿用主仓库 MIT 许可。
- COAST FM 为 Web Audio 实时合成原创双曲目电台；GTA V 商业原声仅通过官方 Spotify 播放器播放，不属于项目 MIT 资产。

托管配置在 `.openai/hosting.json`。部署只包含配置和 `dist/`。
