# Sunset Coast — 霓虹海滨都市

[公开体验](https://sunset-coast-drive-linyang.yanglinchasel.chatgpt.site) · [Blender 与 GitHub 工程](https://github.com/LinYangBIT/gta6)

横屏优先的原创开放城市原型。从人物步行开始，可领取委托、驾驶场景中的任意车辆、下车交付包裹，或自由探索持续生成的街区。城市、角色和车辆在浏览器中本地运行。默认 BGM 是自托管的 PULSE FM 英文人声舞曲；另可选择 Spotify 官方原声。

## 操作

- 步行：WASD / 方向键移动，Shift 奔跑，E 与联络人交谈或上下车。
- 驾驶：W 加速，S 减速与倒车，A / D 转向，空格手刹；停稳后 E 下车。
- 直升机：W / S 前进与后退，A / D 转向，Space 上升，Ctrl 下降；松开升降保持高度，降落停稳后 E 下机。手机使用独立上升 / 下降键。自行车和卡车沿用地面驾驶键。
- 镜头：拖动画面自由环视，C 切换跟随、侧面、第一人称和俯瞰，V 回正；滚轮 / 双指缩放。
- 音乐：点击“进入城市”即播放 PULSE FM 英文人声舞曲；M 打开 / 收起设置，顶部播放 / 暂停键控制音乐，N 切歌。收起设置或返回菜单不会停止音乐。封面上方同样保留这两个音乐按钮。引擎声默认开启，点击进城时解锁、上车后发声；随速度平滑变化，卡车更低沉、直升机有旋翼节奏；自行车、步行、CG、菜单和后台不发引擎声。右上角声音按钮可单独关闭，重新进入会保留本次手动关闭状态。Esc 打开菜单，R 回到起点并重新开始委托。
- 转向配置：点右上角“操控设置”按钮，转向幅度可调 60%–200%，响应速度 60%–180%；默认 130% / 115%。滑块即时生效并保存到本机，换车和换城市保留，可一键恢复推荐。
- 清晰度：操作指南中可选自动、高清、均衡和流畅。自动模式优先高清；显式选择高清会保留该设置。
- 手机横屏：左侧摇杆移动或转向，右侧奔跑 / 油门等动作键，中间右侧交互按钮上下车和领取任务。右侧空白画面可拖动环视。竖屏提供旋转提示，也可选择继续。

开始任务后的流程是步行到联络人领取摄影器材，任选一辆车前往黄色停车标记，停稳后下车交付，获得 $300。之后可继续接取按城市种子生成的委托；换车不丢失包裹。自由探索模式暂时隐藏任务指引。任务面板用黄色方向箭头、距离、操作提示和阶段横幅强调当前目标，世界里有高亮环与光柱；默认英文合成语音播报阶段，播报时压低背景音乐，可重播或静音。不支持语音的浏览器仍显示完整英文字幕。进度和车辆位置为当前会话状态；菜单可继续，重新加载或重置会重新开始。

首次进入有约 8 秒的实时 CG：掠过海滨、经过酒店街景，再落到步行角色身后。可点击“跳过 CG”或按 Esc 跳过；动画期间冻结移动，返回菜单后继续仅作短过渡，开启“减少动态效果”时不播放飞行镜头。

默认转向比上一版更灵活，半秒持续打轮的偏航在测试车速下增加约 30%–37%。可独立调节转向幅度与响应速度，仍保留渐进响应、高速稳定限制和快速回正：轻推摇杆适合修正方向，持续推转向仍可完成低速街口转弯，高速急打轮不再瞬间大幅甩向。巡航中任意手动操控会接管。横屏摇杆扩大至 128px，油门至 72×150px，镜头按钮 44px；音乐默认收起为顶部 98×52px 的按钮条，内含两个 44px 按钮，释放任务和操控区域。

## 城市与视觉

沿着起点向西进入六个新目的地：货运工业区（集装箱堆场与门式起重机）、航空站（停机坪、机库、加油设施）、中央交通广场（架空轨道与地面通道）、运动公园、山麓别墅区和夜间集市。海滩起点新增篮球、排球、健身设施、救生站和候车亭；更远的程序化街区继续变化，院落可生成球场、花园、摊位或滑板设施。小地图显示场所和最近 B / T / H 载具的位置与距离。以上为原创城市布局，不是洛圣都地图的完整复制。

最新视觉改为可读性优先的赛博朋克暮景：蓝紫天空、青色与品红灯带、琥珀灯窗，建筑主体采用石墨、青蓝与紫灰，近景和远景共享配色。湿润路面使用较低粗糙度和不规则区域，保留车道与路缘的清晰对比。

建筑增加立体媒体屏、边缘灯轨、屋顶天线、设备棚及管线；街边店招使用本地生成的原创科技主题字样。车辆使用深色金属漆，增加青蓝侧裙灯、分段前灯、洋红尾灯与引擎盖细节。六类载具使用 34 组共享实例批次，近景跑车仅补充两组灯条；城市继续复用已有发光材质，不为每栋建筑添加灯光。

起点改为按网络截图重建可见建筑外观的海洋大道街区：弯曲的滨海主路、带中央绿岛的环岛、斜向连接路、酒店后巷、停车带和跨湾连接路。路网、车辆停放、碰撞、自动驾驶与小地图共用真实道路数据；离开海滨街区后继续进入无限生成的五类城区。

Colony、Dominion、Dixon 和 Coral 酒店采用分别制作的外观，加入圆角墙体、立体窗框与窗台、玻璃分格、阳台栏杆、入口、咖啡座、竖向招牌及屋顶设备。海边有棕榈公园、步道、沙滩遮阳伞和救生亭。载具包含跑车、轿车、SUV、自行车、六轮货运卡车和直升机，均可使用；自行车有踩踏动作，直升机有旋翼和真实升降。小地图 B / T / H 分别标识新类型。角色有步行 / 奔跑动作，任务联系人和街边行人。

## 碰撞与载具

车辆接触按质量计算冲量，同时改变双方速度；停放的车会被推开并继续滑动，偏心撞击产生旋转，卡车比自行车和轿车更重。墙壁限制运动，阻尼让车辆逐渐停下。碰撞有火花、尘土、小碎屑、距离衰减的撞击声和轻微镜头震动；减少动态效果模式关闭镜头震动。车辆、粒子、音频和碰撞事件均有数量上限。

直升机有独立升降和水平飞行，建筑按高度碰撞；必须回到地面停稳才能下机和完成停车任务。飞行模型是适合键盘与触屏的街机模型。自行车轻巧，卡车更慢且转弯半径更大，原有转向设置仍可调。

## 音乐

默认 **PULSE FM** 播放两首自托管的英文人声电子舞曲，点击进城直接开始，不依赖第三方播放器加载。自动轮播，N / 下一首切歌；收起面板、打开帮助、返回菜单不停止音乐，手动暂停不会被重新进入覆盖。英文任务播报时音乐音量暂降至用户音量的 25%。

## 高清封面与细节

封面使用 [Rockstar 官方壁纸页](https://www.rockstargames.com/VI/media/artwork-wallpapers) 发布的完整原图：横版 **3840×2160**、竖版 **1080×1920**，保持画面比例和原色。站点保留“非官方可玩场景”标识，官方封面与 Logo 的来源、哈希及版权记录在 `dist/assets/gta6-cover-attribution.json`；它们不属于项目 MIT 资产。

实时场景新增近景窗框、窗台、阳台立杆、门厅灯具、遮棚细节、轮拱、车门缝、灯组、刹车盘与细化轮辐。原有热带配色现已更新为蓝紫暮景与青蓝、洋红霓虹。六类载具使用 34 组共享绘制批次，远景继续简化，避免把近景细节复制到所有远处建筑。

高清模式启用抗锯齿和更高阴影精度，按屏幕比例提升渲染分辨率；桌面像素预算最高约 4K，手机最高约 420 万像素。自动模式在持续低帧率时逐级平衡清晰度；选择固定高清后不自动降低。新版城市扩展 Blender 港区近景与俯瞰预览为 **1920×1080**，使用实际网页几何与近景跑车灯条；离线光照和网页实时渲染会有差异。

本轮把海滨陆侧建筑从 19 栋增加到 133 栋，保留五座地标；外围每个 128 米街区从 4–6 栋增加到 16–22 栋。楼房组成沿街商铺、围合庭院、住宅区和办公楼群，内部留出服务通道。

城市按位置持续生成，近景手机最多 25 块、桌面 49 块；远景窗口分别覆盖 17×17、23×23 块区域（扣除已加载近景）。远处建筑与近处使用同一布局、位置和主体尺寸，靠近时补充细节，并非不可到达的背景图。手机雾化距离延伸至约 930 米，桌面约 1400 米。远景只使用四组实例绘制，不参与远距离阴影；离开的街区会回收，碰撞缓存仍为 48 块。浮动原点保持远距离精度。汽车保留附近3×3街区，最多记忆64辆改动过的车辆，超出历史上限的久远车辆可重新生成。没有固定地图边界，也不会一次创建无限物体。

## 源码与许可

- `dist/vehicle-specs.js` / `driving.js`：车型质量、尺寸、地面驾驶与飞行。
